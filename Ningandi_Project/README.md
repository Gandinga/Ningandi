## **📋Contents:**

**Ningandi.py** - Core flask server (requires dependencies, see main README file)  
**NingandiGUI.py** - GUI program to control the server and manage DNS for Linux users only (requires dependencies, see main README file)  
**NingandiGUI.desktop** - desktop icon file for NingandiGUI.py (installed automatically by the setup-install.sh, see main README file for details)  
**hotspot-start.ps1** - Powershell script to bypass Windows artificial hotspot startup requirements (requires setup detailed in the main README file)  
**project_images** - Folder containing the icons and image files I created for the this project.
